# 3D Smart House

## Project Overview
The **3D Smart House** is an interactive 3D house project developed using Python and OpenGL. It represents a modern doll house with multiple rooms, furniture, a garden, and different interactive features.

The main purpose of this project is to demonstrate 3D modeling, computer graphics, animation, lighting, and user interaction.

## Technologies Used
- Python
- PyOpenGL
- OpenGL
- GLUT

## House Features
- 3D House Structure
- Bedroom
- Bathroom
- Living Room
- Kitchen
- Staircase
- Garden with Trees
- Swing

## Interactive Features
- Day and Night Mode
- Light ON/OFF Control
- Rotating Ceiling Fans
- Opening and Closing Door
- Moving Furniture Using Mouse and Keyboard
- Interactive Garden Swing

## Controls

| Key | Function |
|---|---|
| 1 | Day Mode |
| 2 | Night Mode |
| L | Light ON/OFF |
| F | Fan ON/OFF |
| O | Open Door |
| C | Close Door |
| W / S | Move Forward / Backward |
| A / D | Move Left / Right |
| Q / E | Move Up / Down |
| J / K / N / M | Move Swing |
| R | Reset Table Position |
| ESC | Exit Project |

Mouse controls are also available for interacting with movable objects.

## Project Objectives
- To understand 3D computer graphics.
- To implement 3D modeling using OpenGL.
- To demonstrate animation and lighting.
- To implement interactive object movement.
- To create a realistic and interactive doll house environment.
